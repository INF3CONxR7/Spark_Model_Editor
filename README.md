# Spark_Model_Editor
Éditeur de modèles Minecraft PlayStation 3 Edition (models.bin) : arbre des modèles, parties et boîtes, modification des positions, rotations, décalages de texture, dimensions et échelle, enregistrement vérifié et sauvegarde .bak. Mises à jour signées, Discord Rich Presence. Windows 10/11, .NET 10.
